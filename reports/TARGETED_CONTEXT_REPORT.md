# 役割別の敵意判定を調整した結果

## 目的

小学生と中学生は裏読みをほとんどせず、高校生、大学生、社会人の順に少しずつ読みを深くし、京都人だけは場面と人間関係を踏まえて京言葉の含みまで読む設定にした。新卒3年目はこのステージ案から外した。

## 実験条件

- `jev-1.13.0`
- 22例（嫌味候補13例、対照9例）
- 各例を3回ずつ、合計132リクエスト
- 小学生から社会人までは発言だけを状態として渡した
- 京都人だけは場面、関係、社会的な会話状況、発言を渡した
- 役割ごとのヒントは、発言だけを読む役ほど慎重に、京都人は婉曲な批判、過剰な敬語、不自然な褒め方、好ましくない比較を読むように記述した
- 実験用の文章は人間による正解ラベル付きデータではない

## 嫌味候補での平均敵意確率

| 役割 | 平均 | 厳密に見抜いた回数 |
| --- | ---: | ---: |
| 純真無垢な小学生 | 16.3% | 0/39 |
| ちょっとやんちゃしてる中学生 | 13.2% | 0/39 |
| 少し背伸びした高校生 | 18.3% | 0/39 |
| 社会がなんとなくわかってきた大学生 | 33.3% | 0/39 |
| 立派な社会人 | 49.9% | 9/39 |
| 京都人 | 96.6% | 39/39 |

「厳密に見抜いた」は、敵意を選び、敵意の確率が0.7以上だった回数。平均値はモデルが返した敵意確率の平均で、ゲームの勝敗判定そのものではない。

小中学生を20%以下に抑えたまま、高校生、大学生、社会人、京都人へ段差ができた。高校生以降の値は目標値の30%、40%、55%より慎重な出力だが、役割の順序と京都人の最終ステージとの差は維持できたため、このヒント設定を採用する。

## 場面を京都人にだけ渡す効果

同じ発言でも、場面を変えると京都人の判定が変わった。

| 発言 | 嫌味の場面 | 素直な場面 |
| --- | ---: | ---: |
| 元気そうなおこさんでおますね。 | 93.7% | 2.7% |
| ええ時計してらっしゃいますわ。 | 91.0% | 6.7% |
| そない迷いのう言い切れはるの、うらやましいわぁ。 | 97.3% | 29.0% |

この差から、京都人ステージでは発言だけを渡すより、場面と社会的な関係を渡す設計のほうがゲーム上の読み合いを作りやすいと判断した。

## 限界

この結果は、今回作った22例と同じモデル設定での探索結果である。京都の人や京言葉全体についての正解率を示すものではなく、人間が実際に嫌味と感じるかの検証も含まない。実際のゲームでは、同じ発言を嫌味にも素直な褒め言葉にもできる場面の書き分けを、ケースごとに用意する必要がある。
